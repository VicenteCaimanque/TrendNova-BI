# 📊 TrendNova - Arquitectura de Datos y Business Intelligence

## 📝 Descripción
Proyecto integral de Inteligencia de Negocios diseñado para procesar, almacenar y visualizar datos operativos. Se desarrolló una arquitectura completa desde el modelado de procesos de negocio (BPMN) y bases de datos transaccionales (OLTP), hasta la consolidación en un Data Warehouse utilizando la metodología de Ralph Kimball.

## 🎯 Mi Rol y Contribuciones Técnicas
Como parte del equipo de Ingeniería en Informática, lideré las siguientes áreas estratégicas:
* **Modelado de Procesos Core:** Diseño, abstracción y estructuración lógica en notación BPMN 2.0 de los macroprocesos transaccionales críticos (Ciclo de Venta End-to-End y Abastecimiento Logístico B2B).
* **Arquitectura Analítica:** Levantamiento de requerimientos y evaluación metodológica (TCO, conectividad a bases de datos, potencia de cálculo DAX) que justificó la adopción de **Microsoft Power BI** como herramienta corporativa de visualización.

## 🚀 Fases del Proyecto
1. **Modelado de Procesos (BPMN):** Mapeo de reglas de negocio para ventas, despachos, abastecimiento B2B y logística inversa.
2. **Arquitectura de Base de Datos:** Diseño de esquemas relacionales e implementación de scripts de estructura (DDL) y carga (DML) en MySQL.
3. **ETL y Procesamiento:** Transformación de datos estructurados para su integración.
4. **Visualización y BI:** Diseño de métricas para la toma de decisiones empresariales.

## 🛠️ Tecnologías y Herramientas
* **Base de Datos:** MySQL (Workbench, Scripts SQL).
* **Modelado de Procesos:** BPMN.
* **Integración y ETL:** KNIME.
* **Visualización:** Power BI.

## 📂 Estructura del Repositorio
* `/Procesos_BPMN`: Flujos operativos de la empresa (Imágenes).
* `/Base_de_Datos`: Scripts de creación de tablas, relaciones y datos semilla.
* `/Imagenes`: Modelos de la arquitectura relacional y diagramas E-R.
